# 澳洲四城行程地图

2026/10/23 – 11/4 悉尼 → 墨尔本 → 黄金海岸 → 布里斯班 的交互行程页：按天切换路线，看每站介绍和 Google 地图链接、候选酒店（带 Booking 按日期查价）、日出日落，10/31 和 11/2 可以切换白天方案。手机和电脑都能看，跟随系统浅色 / 深色。

**网址：<https://a330209159.github.io/aus-trip/>**

整个网页就是根目录的一个 `index.html`（样式和脚本都写在里面），没有构建步骤。地图用 [Leaflet](https://leafletjs.com) 加 CARTO / OpenStreetMap 底图；景点和酒店按真实坐标放，路线是按顺序连的直线，渡轮和大洋路按途经点画，都是示意。底图或地图组件加载不出来时，行程列表照常能用。

## 发布

推送到 `main` 后，GitHub Actions（`.github/workflows/pages.yml`）会自动发布，一两分钟后网址上就是新版。进度在仓库的 **Actions** 页看。

第一次使用前要在 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**（只需设一次）。

## 改行程

所有数据都在 `index.html` 的 `<script>` 里，搜下面这些变量名就能找到。可以直接在 GitHub 网页上打开 `index.html`，点铅笔图标编辑，提交到 `main` 即可。

注意几点：

- 坐标写成 `[纬度, 经度]`，澳洲纬度是负数。在 Google 地图上右键一个点，第一行就是坐标，可以直接复制。
- 文字用单引号包起来；如果文字里本身有单引号（比如 `Mrs Macquarie's Chair`），整段改用双引号。
- 每一项之间用逗号隔开，少了或多了逗号整个页面会打不开。改完打开网页看一眼；空白的话多半是这里出错了。

### 标记已订酒店

在 `HOTELS` 里找到订好的那家，把 `booked:false` 改成 `booked:true`（每个城市一家）。改完以后：

- 地图上这家酒店始终显示，样式更醒目，标签是「已订 · 酒店名」；
- 当天「住处出发 / 回住处」以及「酒店放行李 / 取行李」这些点自动挪到这家酒店；
- 酒店列表里它排在最前，带「已订」标记；总览页的住宿卡片也会写上它。

区域备选（`areaOnly:true`，比如 North Sydney、Broadbeach）不能标已订。

### `HOTELS`：候选酒店

按城市分组：`syd` 悉尼、`mel` 墨尔本、`gc` 黄金海岸、`bne` 布里斯班。

| 字段 | 含义 |
| --- | --- |
| `n` | 酒店全名 |
| `s` | 地图标签用的短名（可选，没有就用 `n`） |
| `booked` | 是否已订，见上面 |
| `area` | 位置说明，显示在名字旁边 |
| `ll` | 坐标 `[纬度, 经度]` |
| `tags` | 小标签，比如房型、估价（带 `A$` 的会用等宽字体） |
| `note` | 一句说明 |
| `q` | 搜索词，用于「地图」和「Booking 按日期查价」两个链接 |
| `areaOnly` | `true` 表示只是区域备选：地图上是虚线框，没有 Booking 链接 |

入住 / 退房日期不在酒店里，而是在 `CITY` 里每个城市的 `cin` / `cout` / `nights`，Booking 链接会自动带上。

### `DAYS`：每天的行程

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一编号，如 `'d1024'`，也是网址 `#` 后面的部分 |
| `date` / `wd` | 日期 `'2026-10-24'` / 星期 `'周六'` |
| `city` | 当天所在城市（`syd` / `mel` / `gc` / `bne`），决定颜色、日出日落、地图上显示哪个城市的酒店 |
| `night` | 当晚住哪个城市；`null` 表示当晚在飞机上 |
| `region` | 可选。`'gor'` 是大洋路这种离开市区的一天，地图上不显示酒店和同城其他天的点 |
| `tag` / `title` / `lede` | 日期旁的小字 / 当天标题 / 一句话简介 |
| `before` / `after` | 当天开始前 / 结束后的交通卡片，每张是 `{who, code, dep, arr, note}` |
| `start` | `true` 表示从住处出发；也可以写成一个点（大洋路的集合点就是这样），字段同下面的景点 |
| `end` | 回住处，`{mode:'walk'}` 写回去的交通方式；写了 `ll` 就是另一个终点 |
| `stops` | 当天的景点，按顺序排列，字段见下表 |
| `options` | 白天可选方案（有它就不写 `stops`），每个是 `{label, stops, gm}`，页面上出现切换按钮 |
| `tail` | 不管选哪个方案都要走的最后几站，比如回酒店取行李、去机场 |
| `gm` | 「在 Google 地图打开今天的路线」按钮：`{mode:'walking' 或 'driving', list:[...]}`，`list` 里是景点序号（从 0 开始），也可以写 `'start'` / `'end'` |
| `tips` | 提醒，字符串数组 |

**景点（`stops` / `tail` 里的每一项）**

| 字段 | 含义 |
| --- | --- |
| `n` / `en` | 中文名 / 英文名 |
| `ll` | 坐标 `[纬度, 经度]` |
| `t` | 时间，随便写，如 `'约 10:30'` |
| `note` | 说明 |
| `q` | Google 地图搜索词（「地图」链接） |
| `mode` | 从上一站到这一站怎么走，决定地图上的线型：`walk`（默认，实线）、`train` / `tram` / `bus` / `taxi`（虚线）、`ferry`（点线）、`tour` / `car`（点划线）、`flight` |
| `via` | 途经点 `[[纬度, 经度], ...]`，让渡轮、大洋路这类路线按大致走向画，而不是直线 |
| `opt` | `true` 表示可选：淡显，不占编号顺序 |
| `from` / `fromLL` | 可选支线从哪里出发：`from` 写景点序号，`fromLL` 写坐标 |
| `kind` | `'stay'` 酒店（显示「宿」）、`'air'` 机场（显示「机」） |
| `sunset` | `true` 在这站旁边显示日落时间 |
| `nofit` | `true` 表示「复位」时不把这点算进视野（比如很远的机场） |
| `link` | 额外链接 `{l:'文字', u:'网址'}` |

### 其他数据

- `CITY`：每个城市的名字、时区、日出日落用的坐标、默认住处位置 `base`（还没订酒店时用）、算酒店距离的参照点 `anchor`、入住退房日期。
- `FLIGHTS`：总览页的交通表。
- `OV_LEGS` / `OV_CITIES`：总览地图上的航线弧线和城市点；`bend` 控制弧线弯曲方向和程度，`0` 是直线。
