# 澳洲四城行程地图

2026/10/23 – 11/4 悉尼 → 墨尔本 → 黄金海岸 → 布里斯班 的交互行程页：按天切换路线，看每站介绍和 Google 地图链接、每个地点的风景小图、每段路坐什么车（线路号、上下车站、时间、实时查询）、每天大约走多少路和步数、候选酒店（带 Booking 按日期查价）、日出日落，10/31 和 11/2 可以切换白天方案。手机和电脑都能看，跟随系统浅色 / 深色。

**网址：<https://a330209159.github.io/aus-trip/>**

整个网页就是根目录的一个 `index.html`（样式和脚本都写在里面），没有构建步骤。地图用 [Leaflet](https://leafletjs.com) 加 OpenStreetMap 底图；景点和酒店按真实坐标放，公交、电车、渡轮和步行路线沿 OpenStreetMap 里的实际线路和道路画（见下面「路线形状」）。底图或地图组件加载不出来时，行程列表照常能用。

## 发布

推送到 `main` 后，GitHub Actions（`.github/workflows/pages.yml`）会自动发布，一两分钟后网址上就是新版。进度在仓库的 **Actions** 页看。

第一次使用前要在 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**（只需设一次）。

## 底图

默认用 OpenStreetMap 官方瓦片，不需要 key；深色模式下用滤镜把瓦片调暗。

如果想换成 CARTO 的 Positron（浅色）/ Dark Matter（深色）样式：CARTO 从 2026 年 8 月起要求 key，不带 key 的瓦片会印上「API KEY REQUIRED」。到 <https://carto.com/basemaps/apikey/> 免费申请（不用注册账号，非商业用途每月 500 万次请求以内免费），然后在 `index.html` 里搜 `CARTO_KEY`，把 key 填进引号：

```js
var CARTO_KEY = '你的 key';
```

留空就继续用 OpenStreetMap。这个 key 会出现在公开的网页源码里，瓦片服务的 key 本来就是这样用的。

## 改行程

所有数据都在 `index.html` 的 `<script>` 里，搜下面这些变量名就能找到。可以直接在 GitHub 网页上打开 `index.html`，点铅笔图标编辑，提交到 `main` 即可。

注意几点：

- 坐标写成 `[纬度, 经度]`，澳洲纬度是负数。在 Google 地图上右键一个点，第一行就是坐标，可以直接复制。
- 文字用单引号包起来；如果文字里本身有单引号（比如 `Mrs Macquarie's Chair`），整段改用双引号。
- 每一项之间用逗号隔开，少了或多了逗号整个页面会打不开。改完打开网页看一眼；空白的话多半是这里出错了。

### 标记已订酒店

在 `HOTELS` 里找到订好的那家，把 `booked:false` 改成 `booked:true`（每个城市一家）。改完以后：

- 地图上这家酒店始终显示，样式更醒目，标签是「已订 · 酒店名」；
- 当天「住处出发 / 回住处」以及「酒店放行李 / 取行李」这些点自动挪到这家酒店；
- 酒店列表里它排在最前，带「已订」标记；总览页的住宿卡片也会写上它。

区域备选（`areaOnly:true`，比如 North Sydney、Broadbeach）不能标已订。

### `HOTELS`：候选酒店

按城市分组：`syd` 悉尼、`mel` 墨尔本、`gc` 黄金海岸、`bne` 布里斯班。

| 字段 | 含义 |
| --- | --- |
| `n` | 酒店全名 |
| `s` | 地图标签用的短名（可选，没有就用 `n`） |
| `booked` | 是否已订，见上面 |
| `area` | 位置说明，显示在名字旁边 |
| `ll` | 坐标 `[纬度, 经度]` |
| `tags` | 小标签，比如房型、估价（带 `A$` 的会用等宽字体） |
| `note` | 一句说明 |
| `q` | 搜索词，用于「地图」和「Booking 按日期查价」两个链接 |
| `areaOnly` | `true` 表示只是区域备选：地图上是虚线框，没有 Booking 链接 |

入住 / 退房日期不在酒店里，而是在 `CITY` 里每个城市的 `cin` / `cout` / `nights`，Booking 链接会自动带上。

### `DAYS`：每天的行程

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一编号，如 `'d1024'`，也是网址 `#` 后面的部分 |
| `date` / `wd` | 日期 `'2026-10-24'` / 星期 `'周六'` |
| `city` | 当天所在城市（`syd` / `mel` / `gc` / `bne`），决定颜色、日出日落、地图上显示哪个城市的酒店 |
| `night` | 当晚住哪个城市；`null` 表示当晚在飞机上 |
| `region` | 可选。`'gor'` 是大洋路这种离开市区的一天，地图上不显示酒店和同城其他天的点 |
| `tag` / `title` / `lede` | 日期旁的小字 / 当天标题 / 一句话简介 |
| `before` / `after` | 当天开始前 / 结束后的交通卡片，每张是 `{who, code, dep, arr, note}` |
| `start` | `true` 表示从住处出发；也可以写成一个点（大洋路的集合点就是这样），字段同下面的景点 |
| `end` | 回住处，`{mode:'walk'}` 写回去的交通方式；写了 `ll` 就是另一个终点 |
| `stops` | 当天的景点，按顺序排列，字段见下表 |
| `options` | 白天可选方案（有它就不写 `stops`），每个是 `{label, stops, gm, back}`，页面上出现切换按钮；`back` 写这个方案结束后怎么回酒店（如 `{tx:TX.aclandHome}`） |
| `tail` | 不管选哪个方案都要走的最后几站，比如回酒店取行李、去机场 |
| `gm` | 「在 Google 地图打开今天的路线」按钮：`{mode:'walking' 或 'driving', list:[...]}`，`list` 里是景点序号（从 0 开始），也可以写 `'start'` / `'end'` |
| `tips` | 提醒，字符串数组 |

**景点（`stops` / `tail` 里的每一项）**

| 字段 | 含义 |
| --- | --- |
| `n` / `en` | 中文名 / 英文名 |
| `ll` | 坐标 `[纬度, 经度]` |
| `t` | 时间，随便写，如 `'约 10:30'` |
| `note` | 说明 |
| `q` | Google 地图搜索词（「地图」链接） |
| `img` | 列表里方形小图用哪个维基百科（英文）条目的照片，如 `'Sydney Opera House'`；可以写几个备选 `['Coogee Beach', 'Coogee, New South Wales']`；也可以写 `'File:文件名.jpg'` 直接指定 Commons 上的一张图，或 `'search:关键词'` 在 Commons 搜图（见下面「地点照片」）。不写就显示占位图标（酒店、回住处这类点就是这样） |
| `mode` | 从上一站到这一站怎么走，决定地图上的颜色和线型（见下面「地图颜色和步行统计」）：`walk`（默认）、`train` / `tram` / `bus` / `taxi`、`ferry`、`tour` / `car`、`flight` |
| `tx` | 从上一站到这一站具体怎么坐，写 `TX.xxx` 引用下面的交通段 |
| `via` | 途经点 `[[纬度, 经度], ...]`，让渡轮、大洋路这类路线按大致走向画，而不是直线 |
| `opt` | `true` 表示可选：淡显，不占编号顺序 |
| `from` / `fromLL` | 可选支线从哪里出发：`from` 写景点序号，`fromLL` 写坐标 |
| `kind` | `'stay'` 酒店（显示「宿」）、`'air'` 机场（显示「机」） |
| `sunset` | `true` 在这站旁边显示日落时间 |
| `nofit` | `true` 表示「复位」时不把这点算进视野（比如很远的机场） |
| `link` | 额外链接 `{l:'文字', u:'网址'}` |

### `TX` / `STN`：每段路怎么坐

交通段集中写在 `TX` 里（在 `DAYS` 前面），景点用 `tx:TX.xxx` 引用；连着坐几段（比如先坐巴士再换火车）就写成数组。上下车站的坐标统一放在 `STN` 里。

| 字段 | 含义 |
| --- | --- |
| `mode` | `walk` 步行、`train` 火车、`metro` 地铁、`tram` 电车、`lrt` 轻轨、`bus` 巴士、`ferry` 渡轮、`taxi` 打车 |
| `line` | 线路号，显示成彩色小标签，如 `'373'`、`'T8'`、`'G:link'` |
| `dir` | 方向，如 `'往 Coogee'` |
| `on` / `off` | 上车站 / 下车站的名字 |
| `a` / `b` | 上车点 / 下车点坐标（一般写 `STN.xxx`）；不写就用上一站 / 这一站的位置，中间差的一小段步行会自动补上 |
| `time` / `freq` | 大约多久 / 多久一班 |
| `note` | 补充，比如在哪个站台、要不要刷卡 |
| `osm` | 告诉路线脚本去 OpenStreetMap 找哪条线，如 `{route:'bus', ref:'373'}`、`{route:'ferry', name:'CityCat'}` |

线路号和班次是 2026 年 10 月查的。页面上每段交通都有「实时查询」，会用 Google 地图打开这一段的公交路线和实时班次。

### 地图颜色和步行统计

地图上灰色圆点线是步行，彩色实线是坐车，颜色和线路号标签一致（火车橙、地铁青、电车绿、轻轨红、巴士蓝、渡轮浅蓝虚线，打车 / 自驾 / 旅行团棕色点划线）。

列表里每一段都写了怎么走：坐车的写线路，步行的写大约几分钟、多少米。每天顶部的「今天步行」是站与站之间步行距离的合计（有实际路线按路线算，没有的按直线 × 1.25 估），不含景点里面逛的路和可选支线；步数按每公里约 1,350 步估，步行速度按 4.5 km/h。总览页每天那一行也写了当天步行大约多少公里。

### 路线形状（`GEO`）

地图上的路线形状来自 OpenStreetMap，由 `tools/fetch-routes.mjs` 生成，写在 `index.html` 里 `@geo-begin` 和 `@geo-end` 之间，**不要手改**。

改了景点坐标、交通段，或者标了已订酒店之后，到仓库的 **Actions → Update route shapes → Run workflow**（分支选 `main`）跑一次。它会重新取形状、提交到 `main`，再自动重新发布网页，几分钟后生效。不跑也没关系：取不到形状的段会按直线画，其他功能不受影响。

### 地点照片（`PHOTO`）

列表里每个地点前面的方形小图、地图弹窗顶部的照片，来自维基百科条目里的 Wikimedia Commons 图片，由 `tools/fetch-photos.mjs` 按每站的 `img` 挑选，写在 `index.html` 里 `@photo-begin` 和 `@photo-end` 之间，**不要手改**。

- 先用条目的主图，不合适（地图、标志、示意图、SVG）再看条目里的其他图片；只用 Commons 上自由授权的图片。
- 作者和授权写在地图弹窗的照片下面，点开是 Commons 上的图片页。
- 图片直接从 Wikimedia 的图片服务器加载，只取 320 px 宽的缩略图；加载不了（比如网络限制）就显示灰色占位图标，不影响其他功能。

新加了地点或改了 `img` 之后，到 **Actions → Update photos → Run workflow**（分支选 `main`）跑一次，它会提交到 `main` 并自动重新发布网页。某张图不满意，可以：

- 换一个更具体的条目名（比如用海滩条目代替所在城镇的条目）；
- 写 `'search:关键词'` 在 Commons 搜图，用第一张合适的。加 `intitle:` 只搜文件名，比如 `'search:intitle:"Royal Arcade" Melbourne'`；
- 写 `'File:文件名.jpg'` 固定用某一张。工作流日志里每个地点都写了选中的文件名，用 `search:` 时还会列出搜到的其他几张。

改完再跑一次。

### 其他数据

- `CITY`：每个城市的名字、时区、日出日落用的坐标、默认住处位置 `base`（还没订酒店时用）、算酒店距离的参照点 `anchor`、入住退房日期。
- `FLIGHTS`：总览页的交通表。
- `PAY`：总览页「当地交通怎么付钱」的几条说明。
- `OV_LEGS` / `OV_CITIES`：总览地图上的航线弧线和城市点；`bend` 控制弧线弯曲方向和程度，`0` 是直线。
